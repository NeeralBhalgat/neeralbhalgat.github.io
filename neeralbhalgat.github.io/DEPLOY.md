# Deploy this CS180 portfolio

Repository: https://github.com/NeeralBhalgat/neeralbhalgat.github.io

## Easiest: GitHub web upload
1. Open the repository above.
2. Because it is empty, click **uploading an existing file** (or **Add file > Upload files**).
3. Unzip the downloaded `neeralbhalgat.github.io.zip` file.
4. Drag the **contents inside** the `neeralbhalgat.github.io` folder into GitHub. The repository root must contain:
   - `index.html`
   - `style.css`
   - `README.md`
   - `0/`
5. Commit the upload to `main`.
6. Go to **Settings > Pages**.
7. Under **Build and deployment**, choose **Deploy from a branch**.
8. Select branch `main` and folder `/(root)`, then click **Save**.
9. Visit https://neeralbhalgat.github.io/ and https://neeralbhalgat.github.io/0/ .
